Fastest: a "flash-lite" model, for example gemini-3.5-flash-lite. Tap "Find models" to see what your key can use.

Easiest: a classic token with only the repo box ticked. Or a fine-grained token: Resource owner = the account that owns the site, only this repository, Contents: Read and write. Tokens expire. If publishing says the token is bad or expired, make a new one and tap Save and test.

Keys stay in this browser and are only sent to Google, GitHub and any backup AI provider whose key you add. Shop data is read from Supabase (read-only, public info only). Never paste customer data or passwords into the chat.
