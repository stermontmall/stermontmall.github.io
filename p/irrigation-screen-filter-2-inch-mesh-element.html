Product overview

Help protect drip and sprinkler irrigation equipment with this 2-Inch Irrigation Screen Filter with Mesh Element. Installed inline, the filter screens out suspended debris such as sand, algae and other particles before they can reach emitters and contribute to clogging. It features a black plastic housing, 2-inch male threaded connections, a bottom drain and a removable mesh screen that can be rinsed for routine maintenance.

Product details

For a typical setup, install the filter on the irrigation main line after the pump and before distribution lines, while ensuring the connection type, flow rate and filtration mesh suit your system. Check for leaks after installation and clean the screen as needed; a dirty element can restrict flow and reduce irrigation performance. The screen filter is a useful component for farm irrigation, gardens and other water-delivery systems using compatible fittings.
